## 🚀 快速开始

### 本地运行

```bash
# 克隆仓库
git clone https://github.com/wontons584/conan-personality-test.git

# 进入目录
cd conan-personality-test

# 使用 Python 启动本地服务器
python -m http.server 8888

# 打开浏览器访问
# http://localhost:8888/conan-personality-test.html
```

### 部署到 GitHub Pages

1. 在 GitHub 上创建仓库 `conan-personality-test`
2. 将文件上传到仓库
3. 进入仓库设置 -> Pages
4. 选择 `main` 分支和 `/root` 目录
5. 点击 Save，等待部署完成

## 🧠 测试原理

基于 MBTI 人格理论，通过10道题目测试四个维度：

- **E/I**：外向 / 内向
- **S/N**：感觉 / 直觉
- **T/F**：思维 / 情感
- **J/P**：判断 / 感知

根据得分匹配最适合的柯南角色。
